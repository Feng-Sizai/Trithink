# Trithink · 三件事

离线个人日程与项目管理软件，当前版本 **0.5.0**。

[下载 0.5.0](https://github.com/Feng-Sizai/Trithink/releases/tag/v0.5.0) · [使用说明](使用说明.md) · [Windows 安装说明](安装与使用说明.md) · [更新记录](更新记录.md)

## 功能

- 项目 → 阶段 → 任务，支持截止日期与可选具体时刻；未选时刻默认当天24:00。
- 重要程度：★★★极重要、★★重要、★普通、日常。支持按重要程度或截止时间排序。
- 今日计划支持自动模式及最多三项的手选模式；卡片左键进入项目，右键编辑或删除。
- 月历和每周日程表一键切换，使用一致的用户配色；时间表从06:00至24:00。
- 拖选新建和长按整体移动按15分钟刻度，整体移动保持时长；表单及上下边界调整仍可精确到分钟。
- 右键管理项目关联、重复到未来或删除；长按拖动时可拖入垃圾桶。
- Ctrl+Z撤销本次打开期间的已保存操作，文字编辑保留原生撤销。
- 桌面版每次保存写入本机文件，保留最近100份历史备份；支持损坏恢复及JSON导入导出。
- 速写本、作息记录、饮品统计及完成历史。

当前没有云同步、账号或多人共享服务；GitHub仓库协作不会同步个人资料。

## 使用与数据

Windows x64用户下载发布页的安装程序即可使用，无需开发环境。HTML离线版也在发布页提供，打开后使用浏览器本地存储；两版通过JSON备份迁移数据。

桌面默认资料目录为 `%APPDATA%/ThreeThings`，独立数据文件位于其中的 `auto-backups`：`latest.json`、`previous.json` 和 `history/`。备份可迁移到自选工作文件夹，原读取入口通过目录连接保持访问。个人资料、本机备份、测试资料及开发工具均不进入Git仓库。

## 开发

推荐Node.js 24（见.nvmrc）；浏览器前端不依赖第三方npm包。

```sh
git clone https://github.com/Feng-Sizai/Trithink.git
cd Trithink
npm run check
npm run build
```

仓库当前公开，可直接克隆源码或从发布页下载。

| 命令 | 用途 |
| --- | --- |
| `npm run check` | 语法、全部测试、构建及CSP校验 |
| `npm run build` | 生成dist/三件事-试用版.html |
| `npm run desktop:setup` | 恢复桌面锁定依赖并准备Electron |
| `npm run desktop:dev` | 启动桌面开发版 |
| `npm run desktop:package` | 构建Windows x64安装程序 |

维护源文件后通过构建生成前端，不直接编辑生成目录。桌面依赖单独安装在desktop/；保持固定应用身份及资料目录。参见[开发说明](开发说明.md)、[桌面打包说明](桌面打包说明.md)、[日程表说明](docs/周日程表说明.md)和[验证记录](docs/周日程表验证记录.md)。
