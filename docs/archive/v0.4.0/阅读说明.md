# 三件事 0.4.0 共享项目包

先读“三件事-项目上下文-0.4.0.md”，再看设计演进记录与完整源码文本。源码文件在“源码”目录，图标和桌面构建锁文件都已包含。

双击离线网页演示 HTML 可查看合成示例；浏览器会把你后续输入的内容保存在本机，与桌面程序分别保存。此 ZIP 不包含个人使用数据。

桌面原位置更新已经核验为 0.4.0，但独立 exe 安装器尚未在当前环境生成成功，升级后的原生启动也未实机验证。不要把本共享包当作安装器。

上传项目来源时优先加入 Markdown 上下文、设计演进记录和 TXT 源码。只有来源列表实际显示的文件才算已经加入共享上下文。现有项目成员权限不由本包修改。

文档中的个人电脑路径已经替换为占位符。缓存、node_modules、运行文件、个人记录、本机备份和只适用于原电脑的一键脚本没有收入本包。
