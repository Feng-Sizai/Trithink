# 三件事 0.5.0

本版本将当前日程与项目管理功能汇总为0.5.0。

- 月历与06:00–24:00周日程表，一键切换并沿用用户配色。
- 拖选新建、长按整体移动按15分钟刻度；保留原时长，具体编辑可精确到分钟。
- 日程右键菜单、拖入垃圾桶、未来重复及项目关联。
- 星级重要程度与截止日期/时刻，项目排序和首要任务实时更新。
- 今日任务卡片鼠标操作与Ctrl+Z撤销。
- 本机文件自动保存、最近100份历史备份及损坏恢复，兼容旧数据。

验证：96项自动测试通过；相关桌面鼠标、键盘、重开与备份恢复已按各功能记录验收。版本号变更不改变现有数据格式、应用身份与资料目录。

下载Windows x64安装程序或HTML离线版，并可使用SHA256SUMS.txt核对。源码不包含个人资料、本机备份或测试资料。
