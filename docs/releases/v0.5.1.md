# 三件事 0.5.1

自动模式根据剩余截止时间和星级安排事项：

1. 不足24小时（含已逾期）的事项优先。
2. 其后是三星事项。
3. 剩余24小时至不足48小时的事项排在三星之后、二星之前。
4. 其余按星级从高到低，同星级截止更早的优先。

具体截止时刻参与计算；未选时刻默认截止日期当晚24:00。今日计划每分钟或重新聚焦窗口时检查排序变化。手选顺序、完成卡片的继续操作、普通项目列表的排序方式保持原有行为。
