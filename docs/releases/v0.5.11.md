# 三件事 0.5.11

本版汇总自0.5.1以来的日程管理、保存恢复和上手体验更新。

## 实操教程

- 跟随真实界面创建“学习使用三件事”，学习添加阶段与任务、完成待办、在日程表拖选时间、关联项目和保存速写。
- 所有操作区域统一使用蓝色边框及循环向外扩散的水波，页面保持正常亮度；提示卡根据目标位置调整，需要输入的示例文字放大加粗。
- 使用帮助移至左下角的小问号；支持暂停、关闭后继续，结束后可一键清空本轮练习内容，清理可按Ctrl+Z撤销。

## 今日计划与项目

- 自动模式从全部未完成事项中补足前三条，可展开查看完整队列；暂缓移到队尾，次日清空标记，待办较少时仍可轮换。
- 手选调整与自动模式共享顺序，支持一键置顶；恢复默认会清空当天暂缓和手选改动，重新按规则排序。
- 不足24小时的事项及临期项目下的任务显示红色提醒并保护其优先级；项目卡片任意位置可进入详情，右键可标记整个项目完成，完成历史可恢复。

## 数据保存与日常记录

- 自动保存并恢复页面、项目、日期、队列、滚动与窗口状态；启动按软件保存序号读取最新有效备份。
- Ctrl+S另存手动备份；项目、阶段、任务和日程表单支持未提交草稿，关闭后继续编辑，JSON备份也包含草稿。
- 每日饮品增加喝水，支持历史补记和修改杯数；修复日历备注覆盖项目字段、短日程操作及跨午夜日期等问题，重复同步默认跳过已存在的日期。

141项自动检查通过，并完成Windows桌面与真实离线HTML界面验证。应用身份和资料目录保持不变，兼容旧备份；升级前可导出JSON备份。
