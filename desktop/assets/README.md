# 三件事桌面图标

沿用程序已有的“三”字标志，不修改程序内的界面。

- `icon.svg`：可编辑的矢量原稿。底色为 `#2f634b`，圆角比例为原界面的 `11 / 39`；白色字形已转为矩形轮廓，不依赖系统字体。
- `icon.png`：1024 × 1024，RGBA，圆角外透明。
- `icon.ico`：包含 16、24、32、48、64、128、256 像素的透明 Windows 图标，供安装包、快捷方式和程序窗口使用。

如需修改图标，先编辑 `icon.svg`，再在项目目录运行：

```powershell
python desktop/assets/generate-icon.py
```

生成脚本仅需要开发环境中的 Pillow，使用 4 倍抗锯齿绘制后缩小；正式程序不需要 Python、Pillow、额外字体或网络连接。脚本支持当前 SVG 使用的 `rect` / `g` 图元。
